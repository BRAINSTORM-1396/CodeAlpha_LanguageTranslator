# Language Translation Tool

## About the Project

This is a simple language translation application built with Python and Streamlit. It allows users to translate text between English, French, Spanish, and German.

The application uses Argos Translate to perform translations locally on the computer after the required language models have been installed.

## Features

- Translate text between supported languages.
- Simple and user-friendly interface.
- Select source and target languages.
- Display translated text.
- Warn users when the text is empty or the same source and target languages are selected.
- Perform translations locally without relying on Google Translate.

## Technologies Used

- Python
- Streamlit
- Argos Translate
